A lightweight, read-only, mobile-first monthly WooCommerce sales dashboard.

== Description ==

Woo Sales Dashboard adds a top-level Sales Dashboard page to WordPress admin with revenue, orders, sold items, shipping, AOV, items per order, daily trends and Top Products.

It uses WooCommerce APIs and supports both HPOS and legacy order storage. It does not modify WooCommerce business data and has no external dependencies or telemetry.

== Installation ==

1. Upload the plugin ZIP through Plugins > Add New > Upload Plugin.
2. Activate Woo Sales Dashboard.
3. Open Sales Dashboard in WordPress admin.
